# Legacy models

Model pickers keep explicitly superseded models available under **Legacy models** when browsing a provider. Selecting one works like selecting any other model. Existing selections remain selected, and web favorites and search results keep their usual ordering with a small Legacy label.

The label is organizational: it does not mean a model is unavailable or deprecated. Claude's catalog explicitly marks earlier Opus and Sonnet choices; Haiku remains a current fast option. Codex uses a distinct, nonblank upgrade target reported by its live model catalog, while keeping catalog defaults in the normal group.

Unknown models, older snapshots without lifecycle metadata, and custom settings entries stay in the normal group. Adding a custom entry that matches a built-in model does not duplicate or reclassify that built-in. Mobile preserves missing selected models as selectable fallback entries.
