# Thread sidebar

Pin a thread from its context menu to keep it in the pinned section. Sidebar V2 groups pins above
active threads; the original sidebar keeps a pinned section within each project group. Imported
session history cannot be pinned.

Use `mod+shift+p` to pin or unpin the open thread when its server supports pinning. Pinning does not
prevent a thread from being settled or snoozed.

**Settings > General > Unpin confirmation** optionally asks before unpinning through the web or
desktop sidebar controls, thread menus, or keyboard shortcut. It is off by default. Cancelling
keeps the thread pinned. When no confirmation dialog is available, unpinning proceeds directly.
Mobile unpins immediately.
